# Data Science Internship – CodeAlpha

Tasks completed as part of the CodeAlpha Data Science Internship. Each script is a standalone Python program covering a core data science workflow — from EDA to model building and evaluation.

## Task 01 – Iris Flower Classification

`Task_01_iris_classification.py`

Classifies iris flowers into three species based on measurements:

- Loads and explores the Iris dataset (setosa, versicolor, virginica)
- Trains and compares multiple classification models using Scikit-learn
- Evaluates accuracy and generates a confusion matrix
- Visualizes feature relationships with a pairplot

Run: `python Task_01_iris_classification.py`

## Task 02 – Unemployment Analysis with Python

`Task_02_unemployment_analysis.py`

Analyzes unemployment rate data in India:

- Cleans and explores unemployment data
- Investigates the impact of Covid-19 on unemployment trends
- Identifies seasonal patterns and regional differences
- Visualizes findings with region, trend, and seasonality charts

Run: `python Task_02_unemployment_analysis.py`

## Task 03 – Car Price Prediction with Machine Learning

`Task_03_car_price_prediction.py`

Predicts car selling prices from car features:

- Cleans and preprocesses car listing data (age, mileage, fuel type, transmission)
- Trains and compares Linear Regression and Random Forest Regressor
- Evaluates models using R², MAE, and RMSE
- Visualizes correlation heatmap, feature importance, and actual vs. predicted prices

Run: `python Task_03_car_price_prediction.py`

## Tech Stack

Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn
